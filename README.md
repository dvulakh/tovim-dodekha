## Hacking

Compiled with `xelatex` via `latexmk` --- see the included
[makefile](makefile). I use the `latexmk` invocation there with
`-interaction=nonstopmode` for interactive editing. A clean build is
quite slow, but I find the pdf reflects small iterative changes within
seconds.
